# Проверка интерфейса

Проверено в Google Chrome 158.0.8127.36. Автоматизация проверки выполнялась внешним инструментом; в самом проекте нет библиотек и JavaScript.

| Проверка | Результат |
| --- | --- |
| Переход к каждому из 32 экранов | Открывается ровно один экран с одним видимым `h1` |
| Ширины окна 1440, 768, 390 и 320 px | Все 128 сочетаний проверены; горизонтального переполнения нет |
| Общие header и footer | Присутствуют на каждом экране |
| Внутренние ссылки и переходы форм | Все целевые `id` существуют |
| Идентификаторы HTML | Повторов нет |
| Подписи полей | Все поля имеют связанные `label` |
| Фильтр каталога | Все 5 средств / только сапборд / катер и лодка |
| Сортировка каталога | Дешевле сначала / дороже сначала; визуальный порядок меняется |
| Проверка количества человек | Значение 0 отклоняется встроенной проверкой HTML |
| Создание брони | Форма → подтверждение → экран результата |
| Переключение списка | Страница 1 → страница 2 с историей |
| Редактирование и отмена | Открываются соответствующие результаты |
| Добавление пользователя и вход | После заполнения обязательных полей открывается результат |
| Запуск по `file://` | Каталог, фильтр и изображение прототипов доступны |
| Ошибки браузера / HTTP-ошибки ресурсов | Не обнаружены |
| Сторонние скрипты, `<table>`, встроенные стили | Отсутствуют; подключён один `styles.css` |

Снимки основных экранов сохранены в `screenshots/`. Отдельно визуально просмотрены главная, форма бронирования, список пользователей и мобильная главная.

Поиск, сохранение, удаление, расчёт стоимости, бизнес-правила и доступ по ролям проверялись как переходы к готовым состояниям, поскольку задание требует статический макет. Фактическая запись данных и серверные проверки не реализованы.

Отчёт записан в Google Документ через MCP. После записи проверены 12 заголовков разделов, 6 встроенных изображений с подписями и ссылка на репозиторий. Экспортированный PDF содержит 10 страниц A4; страницы отрендерены и просмотрены, обрезанного текста, наложений и пропавших изображений не обнаружено. Этот экспорт сохранён как `report.pdf`.
