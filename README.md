## Запуск

Открыть `UI/index.html` в Google Chrome. Установка пакетов и сборка не нужны.

Можно запустить из корня проекта через локальный сервер:

```bash
python3 -m http.server 8000
```

Затем открыть [http://localhost:8000/UI/index.html](http://localhost:8000/UI/index.html).

## Что посмотреть

- Главная страница и пустой список бронирований.
- Каталог: фильтрация по типу средства и сортировка по цене работают на CSS.
- Создание брони: форма → проверка → подтверждение → готовый результат.
- Мои брони: поиск, две страницы списка, просмотр, редактирование и отмена.
- Ошибки: нарушение правила 2 часов и недоступность средства/инструктора.
- Абонемент и пример его заморозки.
- Расписание инструктора и отчёт руководителя.
- Пользователи: добавление, редактирование и подтверждение удаления.
- Раздел «Карта экранов»: все основные переходы и схема прототипов.

Для демонстрации удобно пройти сценарий из [docs/demo.md](docs/demo.md).

## Границы макета

По заданию выполнена статическая вёрстка без JavaScript, сервера и сторонних библиотек. Экраны переключаются ссылками по якорям и селектором `:target`. Нативные HTML-формы проверяют обязательные поля и диапазоны, затем открывают фиксированный пример результата. Отправка формы может перезагрузить тот же HTML-файл; полноценная SPA-логика не реализуется на этом этапе.

Поиск, сохранение, удаление, вход, расчёт суммы и проверка ресурсов показаны готовыми состояниями. Введённые данные не передаются в эти состояния и не записываются. Фильтрация и сортировка небольшого каталога выполняются непосредственно через CSS `:has()` и `order`.

Имена, контакты, цены, адреса площадок и показатели — учебные примеры. Время примера зафиксировано: **24.06.2027, 10:00**, поэтому ближайшее допустимое начало брони — **12:00**. Реальная проверка правила «не ранее чем через 2 часа» относится к следующему этапу разработки.
